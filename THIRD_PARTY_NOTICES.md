# Third-party components

The Git backend derives from dsh-source-control (MIT); its copyright notice is retained in LICENSE.

The locally bundled diff editor uses Microsoft Monaco Editor 0.57.0 (MIT), including Codicons. Its original license is distributed as lib/assets/monaco.LICENSE.txt.

Monaco's bundled dependencies include DOMPurify 3.4.17 (dual Apache-2.0 / MPL-2.0); the original license text is distributed as lib/assets/dompurify.LICENSE.txt. Dependency versions are recorded in package-lock.json.
